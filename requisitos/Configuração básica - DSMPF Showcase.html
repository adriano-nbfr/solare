Configuração básica de uma aplicação usando a biblioteca ngx-dsmpf

Habilitando a configuração básica nos providers da aplicação

Caso você ainda não tenha feito a instalação da biblioteca, certifique-se de primeiro executar todos os passos descritos na página Instalação da biblioteca antes de prosseguir.

Uma vez seguidos corretamente os passos da instalação, já é possível utilizar diversos elementos disponíveis na biblioteca (componentes, diretivas etc) de maneira avulsa.

Contudo, para obter o máximo de ajuda na construção de aplicações padronizadas (layout, dados de autenticação etc) e até mesmo acelerar a produção de telas de Crud, recomenda-se habilitar a configuração básica da biblioteca para aplicações que seguem o modelo por ela fornecido.

No arquivo app.config.js, Use a função provideConfiguracaoBasica() para fornecer todas as dependências e configurações básicas para o funcionamento de uma aplicação comum, a partir de alguns parâmetros. Segue um exemplo mínimo de configuração: 

        
          export const appConfig: ApplicationConfig = {
  providers: [
    provideConfiguracaoBasica({
      parametrosAplicacao: environment.parametrosAplicacao,
      parametrosSeguranca: environment.parametrosSeguranca,
      rotas: { primeiroNivel: appRoutes, gerarEstruturaPadrao: true }
    })
  ]
};

As rotas fornecidas ficam configuradas no arquivo correspondente, app.routes.ts. No o exemplo acima, o valor true na opção gerarEstruturaPadrao faz com que a biblioteca inclua automaticamente o componente de arcabouço no topo da hierarquia de rotas.

Quanto aos parâmetros, os relativos à segurança podem ser omitidos caso sua aplicação não envolva autenticação.

Para uma maior organização e versatilidade, esses parâmetros podem ser definidos em um arquivo à parte, de forma que seus valores possam variar conforme o ambiente (desenvolvimento / produção). No Angular, uma maneira comum de conseguir isso é por meio de arquivos de environment, conforme ilustrado na próxima seção.

Fornecendo os parâmetros da aplicação usados pela biblioteca

Segue um exemplo de arquivo environment.ts contendo algumas configurações de uma aplicação que segue o modelo fornecido pela biblioteca: 

        
          const parametrosAplicacao: DsParametrosAplicacao = {
  nome: "DSMPF Demo Fullstack",
  sigla: "dsmpf-demo",
  logo: {
    src: "logo-dsmpf.svg",
  },
  basePath: "/dsmpf-demo",
  api: {
    raiz: "/api",
    informacaoSistema: "/api/public/informacao-sistema"
  }
}

// Parâmetros de autenticação/autorização específicos (definidos no back end)
const parametrosSeguranca: DsParametrosSeguranca = {
  api: {
    usuarioAutenticado: "/api/__seguranca/usuario",
    atuacoes: "/api/__seguranca/atuacoes-json",
    papeis: "/api/__seguranca/papeis",
    atuacaoCorrente: "/api/__seguranca/atuacoes/atual",
    atuacaoEscolha: "/api/__seguranca/atuacoes",
    logout: "logout"
  },
  csrf: {
    endpointToken: '/api/__seguranca/csrf'
  }
}

/** Parâmetros de ambiente usados na configuração da aplicação */
export const environment = {
  production: false,
  parametrosAplicacao: parametrosAplicacao,
  parametrosSeguranca: parametrosSeguranca
}

Além dos atributos ilustrados acima (alguns deles opcionais), existem outros que permitem ajustes mais finos das configurações da aplicação. Todos eles possuem boa documentação que pode ser visualizada diretamente no seu editor enquanto você escreve seu código.

Feito isso, sua aplicação estará completamente configurada para usar todos os recursos da bibloteca ngx-dsmpf.
